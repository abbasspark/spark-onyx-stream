# Security Policy

## Reporting a vulnerability

**Do not report security problems in public issues, discussions or pull requests.**

Use GitHub's private vulnerability reporting instead:

1. Open the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem, the affected component and the steps to reproduce it.

Include, if you can:

- the version or commit you tested;
- the impact you expect (for example unauthorized playback, account takeover, remote code execution);
- a proof of concept.

## What to expect

- Your report is acknowledged as soon as possible.
- You are kept informed while the problem is investigated and fixed.
- Once a fix is released, the problem is disclosed publicly and you are credited, unless you prefer to stay anonymous.

Please give the project reasonable time to release a fix before you disclose the problem yourself.

## Supported versions

The project has no stable release yet. Until the first stable release, only the latest commit on `main` receives security fixes.
