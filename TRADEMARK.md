# Trademark Policy

> **Draft.** This policy has not yet been reviewed by a lawyer.

The source code of Spark Onyx Stream is open source under the AGPL-3.0. The **name and logo are not**. "Spark Onyx Stream", "Onyx Stream" and the project logos ("the Marks") belong to Abbas Bandar.

This policy exists so that people can trust that something called Spark Onyx Stream really is this project.

## You may, without asking

- Use the name to refer to the project truthfully, for example "built on Spark Onyx Stream" or "compatible with Spark Onyx Stream".
- Use the name in articles, talks, tutorials and reviews about the project.
- Run an unmodified version for yourself or your organization and call it Spark Onyx Stream.

## You may not, without written permission

- Use the Marks as the name of a modified version or fork. A fork needs its own name and logo.
- Use the Marks in the name of a company, product, service, domain or social media account.
- Sell hosting, support or other commercial services under the Marks in a way that suggests you are the project or are endorsed by it.
- Change the logo or combine it with other marks.

## Forks

The AGPL lets you fork the code. If you distribute a modified version, remove the Marks from it and choose a different name. You may state that your version is "based on Spark Onyx Stream".

Open an issue in this repository.
